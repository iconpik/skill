# iconPik Agent Skill

Find and integrate verified [iconPik](https://www.iconpik.com) brand logos, cloud architecture icons, flags, and UI icons.

## Install

```sh
npx skills add iconpik/skill
```

[View on skills.sh](https://skills.sh/iconpik/skill/iconpik).

Supports agents recognized by the skills CLI. Select your agent during installation.

Try: "Use iconpik to add a GitHub logo and an outline search icon to my project."

The skill resolves real catalog entries and asset variants before generating framework code. It includes references for brand assets, UI icons, and React/Vue/Svelte/HTML integration, plus an optional read-only Python 3 search helper with no third-party dependencies.

This repository contains only the distributable skill, not the iconPik application or full icon collection.
